Tech and finance firms are preferred — environments with mature data cultures, real analytics investment, and roles where BI/data engineering is a core function, not an afterthought. Avoid pure staffing/body-shop arrangements without a named end-client.

## Addressing-Weaknesses Analysis

### Weakness 1: Certifications in progress, not yet complete
PL-300 (Power BI Data Analyst Associate) and DP-203 (Azure Data Engineer Associate) are actively being pursued but not yet on the resume as earned credentials.

**How to address:** Lead with 10+ years of hands-on delivery — the track record (25% processing time reduction, 20% plan improvement, three enterprise data warehouses built from zero) demonstrates the competency the certs confirm. Call out certs as "in progress" in resume header. For roles that screen on certs, this is a minor flag; for roles screening on delivered outcomes, it's a non-issue. Close the certs as soon as possible to remove the objection entirely.

### Weakness 2: Limited non-Microsoft stack depth
AWS, Snowflake, and dbt appear in the skills section but without specific project context to back them up. Most hands-on project experience is on the Microsoft stack (Azure, SQL Server, Power BI, SSIS, ADF).

**How to address:** Position explicitly as a Microsoft data stack specialist — this is a strength in most enterprise BI and Power BI-specific roles, not a gap. For roles requiring heavy AWS/Snowflake/dbt, acknowledge limited hands-on depth honestly and emphasize transferable architecture skills (dimensional modeling, ETL design, semantic layer thinking translate across platforms). Do not over-claim on these in interviews. If a role is primarily Snowflake/dbt-centric, filter it lower in priority.

### Weakness 3: Microsoft Fabric experience not yet documented
Has hands-on production Fabric experience at Carnival and Basic Fun (lakehouses, ETL pipelines, golden datasets) but it is not currently reflected on the resume or LinkedIn. This is actually a competitive differentiator — most BI developers have not deployed Fabric in production — but only if it's visible.

**How to address:** Add Microsoft Fabric explicitly to resume skills and work experience bullets at Carnival and Basic Fun. Lead with it as an early-adopter signal in interviews and outreach. Fabric is a major strategic direction for Microsoft; being ahead of most of the market on it is a genuine advantage.

## Dream Offer

**Company:** Fully remote tech or finance firm
**Role:** Lead BI Developer / Senior BI Engineer
**Comp target:** $150,000 base salary (or $70–75/hr for contract)
**Why this specifically:** Combines the full Microsoft data stack ownership (Power BI, Azure, ETL, semantic modeling) with a remote setup, strong compensation, and a team that treats BI as a first-class function — not a support service.
**What would make you say no:** Below $130K base / below $70/hr; on-site requirement without significant comp premium; staffing firm placement without named client; role where Power BI is incidental rather than central.
