The Job Hunt as one graded pipeline

Six subsystems that pull roles from every channel — inbox, web, LinkedIn, recruiters — grade each against one career plan, and route only the good ones to action. Built for ~20–30 minutes of judgment a day; the machinery does the scanning.

02

Operating principles

Precision over volume

One deeply-tailored pursuit a day beats spray-and-pray. Every output cites real context.

Real experience only

Never fabricate a skill, metric, or bullet. Unmatched requirements are flagged as gaps, not invented.

Referrals before cold apply

A referral is ~5× a cold application. The referral path gets built first, every time.

The system compounds

Each connection, debrief, and application sharpens the next. Nothing is thrown away.

Discovery · inbound

Recruiter Inbox

Scheduled

A daily Gmail scan that pulls human-recruiter emails, scores each against the career plan, and surfaces them for a one-glance triage. Acting on a role tailors a resume and drafts the reply — with the PDF attached — through Outlook.

Gmail→ score & label → dashboard + widget → act
recruiter-inbox-scanDaily ~07:57 scheduled task → writes the tracker, labels threads (Strong/Look/Low), syncs the widget.
/recruiter-scanThe same scan on demand — wired to the widget's refresh button.
/recruiter-actionAnalyze one thread → tailor resume into an application folder → draft the Gmail reply with the PDF attached (Outlook COM engine).
/job-fit-inbox · /next-stepsRead-only fit score, and a stage-aware next-steps plan grounded in the methodology.
dashboard/recruiter-inbox.html RecruiterInbox widget recruiter-inbox.md

Discovery · outbound

Job Hunt

On-demand

The open-market channel. Pulls good-fit postings from job-alert emails and a live web sweep, grades them, and keeps a direct-source x-ray board for hitting company ATS platforms hours before the aggregators.

Alerts + web sweep→ grade (strong-only from sweeps) → dashboard + widget
/job-hunt-scanScan job-alert emails + run the saved sweeps (LinkedIn/Dice/Indeed + Glassdoor/Wellfound/BuiltIn x-rays) → merge strong fits, refresh the widget.
/board-scanClaude runs rotating ATS x-ray searches itself and reports only 65+ fits — no clicking 40 links.
job-hunt-sweep.jsonSingle source of truth: 14 title families → one Boolean the sweeps rebuild from.
job-title-search-list.md · job-search-tracker.mdThe 120-day title corpus and the board-coverage tracker that feeds the briefing.
dashboard/job-hunt.html (tabbed) JobHunt widget

Discovery · inbound

LinkedIn Scan

On-demand

Reads LinkedIn's native Jobs-filtered messages through the logged-in browser, grades each recruiter outreach on the same rubric, and merges good fits into the Recruiter Inbox — tagged LinkedIn and linking back to the conversation. Read-only; never sends.

LinkedIn messages→ grade → Recruiter Inbox (source-tagged)
/linkedin-scanBrowser-driven (needs a logged-in session — on-demand only, not headless). Dedupes against the pipeline; flags any message requesting PII.
merges into RecruiterInbox dashboard + widget cards link to the LinkedIn thread

Delivery · per role

Resume & Fit

On-demand

Turns a graded role into an application. Score the fit, tailor an ATS-clean resume from real experience with a coverage score and a bullet-by-bullet traceability audit, then auto-review it through recruiter and ATS lenses before it's ever sent.

JD→ fit score → tailored resume + coverage → reviewed PDF
/quick-start60-second go/no-go on any JD — red flags, salary estimate, verdict. Zero setup.
/job-fit-scorerScore a JD 0–100 across 5 dimensions: apply, apply-with-referral, or skip.
/resume-tailorKeyword-coverage score up top, every bullet traced to the library, [UNVERIFIED] gaps flagged, built to a one-page PDF.
/review-as-recruiter · /review-as-atsAuto-run after tailoring — a 6-second recruiter scan and an ATS-parse check, then auto-correct.

Orchestration

Daily Briefing

Scheduled

The morning layer that sits on top of everything: scans target companies for new roles, surfaces the stalest board searches to run, generates the day's networking batch, and calls out the single biggest pipeline bottleneck.

part2-networkingThe day's connection requests (≤200 chars), follow-ups, and referral nudges.
part3-coachingPipeline health, interview-weakness coaching, and a time-boxed priority stack.
runs ~7:00–7:30, weekdays (app open)
04

The 20–30 minute daily loop

What the machinery hands you each morning, and where your judgment actually goes.

READ

The briefing

Top roles, board searches to run, networking batch, today's bottleneck.

TRIAGE

Two dashboards

Recruiter Inbox + Job Hunt — set dispositions on anything new since yesterday.

ACT

One strong fit

/recruiter-action or /resume-tailor the single best role — build the referral path first.

OUTREACH

Send the batch

Connection requests + any drafted replies. You review and send; the OS never sends for you.

LOG

Track it

/app-tracker keeps the pipeline honest and feeds tomorrow's briefing.
